## Task 3.2 – Understand Processes

1. What is a process?

A process is a program or application that is currently running on a computer. The operating system manages these processes and allocates resources to them.

2. What does the PID column represent?

PID stands for Process ID. It is a unique identification number assigned to every running process by the operating system. It helps the operating system identify and manage individual processes.

3. Give two examples of processes that may be running on your computer.

1. Brave Browser – A process used for browsing websites and accessing the internet.
2. Visual Studio Code – A process used for writing, editing and running code.


## Task 3.3 – Understand Paths and Permissions

Absolute Path vs Relative Path

An absolute path gives the complete location of a file starting from the root directory. A relative path gives the location of a file based on the current working directory.

| Path type | Example |
|---|---|
| Absolute path | /Users/user1/Desktop/digital-detective-8004/mission-03-operating-system/README.md |
| Relative path | mission-03-operating-system/README.md |

## Task 3.4 – Explain Operating-System Responsibilities

| OS responsibility | Your explanation | Example |
|---|---|---|
| Process management | The operating system manages running programs and allocates CPU time to them | Running Brave Browser and VS Code simultaneously|
| Memory management| It manages RAM and allocates memory to different applications| Giving memory to a browser while watching a video|
| Device management| It controls and communicates with connected hardware devices| Managing the keyboard, mouse and printer|
| File management |It organizes, stores, retrieves and deletes files and folders| Creating, renaming and deleting files|
| User interface / shell| It provides a way for users to interact with the computer| Using macOS desktop or Terminal|
| Security and permissions| It protects files and system resources by controllig user access| Requiring a password to access an account|
