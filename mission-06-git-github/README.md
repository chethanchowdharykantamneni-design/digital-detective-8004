
## Task 6.1 – Understand the Basic Git Workflow

| Git operation | What it does in my own words|
|---|---|
| Check repository status|Shows the changes made in the project|
| Stage selected changes|Selects the files to be included in the next commit|
| Create a commit|Saves the selected changes with a message|
| View commit history |Shows the previous commits made in the repository| 

Difference between staging and committing

Staging means selecting the changes that I want to save. Committing saves those selected changes in the Git history with a message.

## Task 6.4 – Git Command Glossary

| Git command | Explanation |
|---|---|
| `git init` | Creates a new local Git repository. |
| `git status` | Shows the current status of files. |
| `git add` | Selects changes for the next commit. |
| `git commit` | Saves changes in Git history. |
| `git log` | Displays previous commits. |
| `git branch` | Creates or lists branches. |
| `git switch` | Changes from one branch to another. |
| `git push` | Uploads local commits to GitHub. |
| `git pull` | Downloads and integrates remote changes. |
