| Point | Compiler | Interpreter |
|---|---|---|
| When  execution happens | Converts the whole program before running it. | Reads and executes the program during runtime, usually line by line. |
| Typical output | Produces machine code or an executable file. | Executes the code without usually creating an executable file. |
| One example | C | Python |
| One advantage | The program can run faster after compilation. | Errors can be found and tested more easily while running the code. |

### Difference between a compiler and an interpreter

A compiler converts the whole program into machine code before it runs

An interpreter reads and executes the code  line by line

A compiler can make the program run faster while  interpreter makes testing and debugging easier 

Both are used to execute programs.
